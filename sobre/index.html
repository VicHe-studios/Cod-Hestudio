Sobre Cod-Hestudio

Un editor de código que vive en tu navegador, con plugins que activas solo si los necesitas. Aquí contamos qué es, por qué existe, cómo funciona y quién está detrás.

Qué es

Un editor ligero, sin instalación y a tu medida

Cod-Hestudio es un editor de código que se abre en el navegador. Trabajas directamente sobre las carpetas de tu computadora, con un editor del mismo tipo que usa Visual Studio Code por dentro (Monaco), y con un sistema de plugins que añaden funciones: búsqueda, notas, vista previa, exportación a ZIP, sincronización con GitHub y más.

Nada se instala. Nada se sube a internet, salvo que decidas exportar a GitHub. No hay cuentas ni suscripciones.

Por qué existe

Un editor que crece sin hincharse

Cod-Hestudio nació como una herramienta personal para escribir y revisar proyectos web sin depender de instalaciones pesadas. Con el tiempo se volvió un laboratorio: cada función nueva se construye como plugin, para que el núcleo siga siendo pequeño y que cada quien active solo lo que usa.

La idea es sencilla: un editor que se adapta a cómo trabajas, y no al revés.

Cómo funciona

Tres ideas que sostienen el proyecto

Tus archivos, en tu PC

Abres carpetas locales y editas directamente. El editor lee y escribe en tu disco, sin copias intermedias.

Plugins a tu medida

Activas y desactivas funciones desde la tienda. Lo que no usas no ocupa lugar en la barra ni en la memoria.

Sin cuentas

No pedimos correo ni contraseña. Tus proyectos y tu configuración se quedan en tu navegador.

Requisitos

Dónde funciona

Cod-Hestudio usa la File System Access API para leer y escribir carpetas de tu computadora. Esa API está disponible en Google Chrome y Microsoft Edge. En Firefox y Safari algunas funciones no van a estar disponibles.
